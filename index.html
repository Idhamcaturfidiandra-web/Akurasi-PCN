Item Selisih WMS vs NAV

Prioritas Cycle Count per Lokasi

Item selisih tanpa lokasi WMS

Lokasi per Zone

Per Salesperson

Item terjual per Salesperson Name (Sales Detail Report By Salesperson). Hanya nota bertipe Cash&Carry via Pickup & Delivery, Cash&Carry via Gudang Store, dan Bawa Langsung (nota tidak ditemukan di Nota Penjualan By NAV). Status item: Done bila total Moved Qty ke X333 (Report Stock Movement) ≥ total terjual semua salesperson; Kurang Move bila kurang. Klik baris untuk melihat itemnya.

Detail Item per Salesperson

Qty Salesperson = total Quantity item oleh salesperson tsb. Total Terjual = total Quantity item itu oleh seluruh salesperson. Moved X333 = total Moved Qty dengan To Storage Location X333, hanya Task AUTO MOVING / MANUAL MOVING. Retur (Quantity minus) tidak dihitung. Selisih = Moved X333 − Total Terjual.

Status

Accuracy By Location

Category = Zone Id di Report Update Location Status. Lokasi aktif = lokasi berstatus Active di report tersebut; Not Process = lokasi aktif yang belum di-cycle count. Akurasi = HIT ÷ (HIT + MISS). Zone Transit, Storage, Staging, Quarantine dan Display Detail tidak ditampilkan. Baris Topper = subtotal semua category non-Warehouse; baris Warehouse = subtotal zone Warehouse. Label abu-abu di samping Category = target lokasi yang harus di-CC per hari (Not Process ÷ sisa hari sampai akhir bulan, termasuk hari ini) agar semua lokasi terakurasi sampai akhir bulan. Lokasi HIT = semua item Matched; MISS = ada item Not Matched.

PIC

PIC = Assigned User di Cycle Count Summary. Akurasi = lokasi HIT ÷ lokasi yang dihitung.

Task belum selesai

Task dengan status selain DONE (task CANCEL tidak ditampilkan).
